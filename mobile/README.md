# UangKita Mobile

Proyek React Native UangKita ada di [UangKita/](./UangKita/README.md), berbasis Expo SDK 57 dengan navigasi Stack yang mendukung kembali ke fitur sebelumnya.

- Aplikasi memiliki `package.json`, `tsconfig.json`, dan dependensi sendiri.
- Jalankan perintah pengembangan dan build mobile dari `mobile/UangKita`.
- Hubungkan aplikasi ke API Next.js yang di-host di Vercel menggunakan URL lengkap.
- Folder ini dikecualikan dari pemeriksaan TypeScript dan ESLint aplikasi web. Jangan mengimpor kode mobile dari aplikasi web.

Aplikasi Next.js dan perintah build web tetap berada di root repository.
